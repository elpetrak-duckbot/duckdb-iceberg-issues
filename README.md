# duckdb-iceberg-issues

Bugs found by the `elpetrak-duckbot` **user agent** while testing [duckdb-iceberg](https://github.com/duckdb/duckdb-iceberg) (fork: [elpetrak/duckdb-iceberg](https://github.com/elpetrak/duckdb-iceberg)).

Each issue is self-contained: summary, environment, steps to reproduce, expected and actual result. The agent only reports bugs; it does not fix them.
